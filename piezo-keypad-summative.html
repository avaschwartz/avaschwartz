Summative Arduino Extension

Making an Arduino play music with a piezo buzzer and a keypad.

Project

Piezo Buzzer + Keypad

I connected a piezo buzzer and a keypad to an Arduino and used code to control the sounds the buzzer makes. I wanted to see how electronics and programming can work together to make something interactive.

What I Built On

The skill I am building on is digital output. In class, I learned how to control an Arduino by making an LED flash on and off. I wanted to take this a step further by making the Arduino control something more interesting than just an LED. So, I decided to learn how to use a piezo buzzer. I chose this because I was interested in how Arduino can combine electronics and programming to create something interactive. I also wanted to learn how different notes can be created using code.

New Components & Research

The new components I used were a piezo buzzer and a keypad. I researched how to connect the piezo buzzer to an Arduino and learned that the tone() function can make the buzzer play different frequencies. Higher or lower frequencies create different musical notes.
