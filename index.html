Unit 1 · Day 8

Summative Arduino Extension

Arduino Light Memory Game — a circuit built through research, trial and error, debugging, and code modification.

Project

Arduino Light Memory Game

I built a memory game using an Arduino, four LEDs, four pushbuttons, resistors, and a buzzer. I started with a YouTube tutorial and then extended the project by changing the code to make the game progressively harder.

What I Built On

I built on my experience with digital inputs and digital outputs from this unit. The game combines buttons as inputs with LEDs and a buzzer as outputs.

Research

I looked up a YouTube tutorial for an Arduino memory light game and used its wiring and example code as my starting point. The original video link can be added here if needed.

Source: YouTube tutorial used for the memory light game

Project Timeline

From first wiring attempt to final game

Step 1 · Getting started

Starting the circuit

I looked up a YouTube tutorial and found a memory light game that I could use as a starting point. I began by laying out the components and figuring out how the LEDs, buttons, resistors, buzzer, and Arduino would connect.

Step 2 · Wiring and troubleshooting

Figuring out the wiring

Getting the wiring right was harder than I expected. I had to restart several times because I put wires in the wrong spots, some lights were not working, and leftover parts from past projects were still stuck in the breadboard.

Step 3 · Arduino connections

Connecting the Arduino pins

Connecting the wires to the Arduino pins was especially tricky because each wire had to go to a specific pin. I kept placing them incorrectly, but after several attempts I finally got the connections set up correctly.

Step 4 · First working test

Getting the circuit to work

I finally got the circuit working, but then I noticed that the yellow light had stopped working. I had to go back through the circuit and figure out what was different about that part of the build.

Step 5 · Debugging

Fixing the yellow light

I eventually realized that the resistors were positioned oddly. I moved each resistor one point closer to its corresponding light, and after making the changes, the lights worked correctly again.

Step 6 · Testing

Testing the working circuit

Once the hardware was working, I tested the buttons, lights, and buzzer together to make sure the circuit could actually function as a game.

Step 7 · Final demonstration

Adding my own challenge

I found the original code in the YouTube video's description and used it as my starting point. I then used ChatGPT to help me add a difficulty system: every five turns, the lights become faster, and a short light show plays to show that the difficulty level has increased.

Final Code

This is the final code I used for the Arduino Light Memory Game, including the increasing difficulty and level-up light show.

View full Arduino code
#define NOTE_C4  262
#define NOTE_E4  330
#define NOTE_G4  392
#define NOTE_C5  523
#define NOTE_CS5 554
#define NOTE_D5  587
#define NOTE_DS5 622
#define NOTE_E5  659
#define NOTE_G5  784

const byte buttonPins[] = {2, 3, 4, 5};
const byte ledPins[] = {7, 8, 9, 10};
#define SPEAKER_PIN 12
#define MAX_GAME_LENGTH 100
const int gameTones[] = { NOTE_C4, NOTE_E4, NOTE_G4, NOTE_C5 };

byte gameSequence[MAX_GAME_LENGTH] = {0};
byte gameIndex = 0;
byte difficulty = 1;

void setup() {
  Serial.begin(9600);
  for (byte i = 0; i < 4; i++) {
    pinMode(ledPins[i], OUTPUT);
    pinMode(buttonPins[i], INPUT_PULLUP);
  }
  pinMode(SPEAKER_PIN, OUTPUT);
  randomSeed(analogRead(A0));
}

void lightLedAndPlayTone(byte ledIndex) {
  digitalWrite(ledPins[ledIndex], HIGH);

  if (difficulty == 1) {
    tone(SPEAKER_PIN, gameTones[ledIndex]);
  } else if (difficulty == 2) {
    tone(SPEAKER_PIN, gameTones[ledIndex] + 100);
  } else if (difficulty == 3) {
    tone(SPEAKER_PIN, gameTones[ledIndex] + 200);
  }

  if (difficulty == 1) {
    delay(300);
  } else if (difficulty == 2) {
    delay(200);
  } else if (difficulty == 3) {
    delay(100);
  }

  digitalWrite(ledPins[ledIndex], LOW);
  noTone(SPEAKER_PIN);
}

void playSequence() {
  for (int i = 0; i < gameIndex; i++) {
    byte currentLed = gameSequence[i];
    lightLedAndPlayTone(currentLed);
    delay(50);
  }
}

byte readButtons() {
  while (true) {
    for (byte i = 0; i < 4; i++) {
      byte buttonPin = buttonPins[i];
      if (digitalRead(buttonPin) == LOW) {
        return i;
      }
    }
    delay(1);
  }
}

void gameOver() {
  Serial.print("Game over! your score: ");
  Serial.println(gameIndex - 1);
  gameIndex = 0;
  difficulty = 1;
  delay(200);

  tone(SPEAKER_PIN, NOTE_DS5);
  delay(300);
  tone(SPEAKER_PIN, NOTE_D5);
  delay(300);
  tone(SPEAKER_PIN, NOTE_CS5);
  delay(300);

  for (byte i = 0; i < 10; i++) {
    for (int pitch = -10; pitch <= 10; pitch++) {
      tone(SPEAKER_PIN, NOTE_C5 + pitch);
      delay(5);
    }
  }

  noTone(SPEAKER_PIN);
  delay(500);
}

bool checkUserSequence() {
  for (int i = 0; i < gameIndex; i++) {
    byte expectedButton = gameSequence[i];
    byte actualButton = readButtons();
    lightLedAndPlayTone(actualButton);
    if (expectedButton != actualButton) {
      return false;
    }
  }
  return true;
}

void playLevelUpSound() {
  tone(SPEAKER_PIN, NOTE_E4);
  delay(150);
  tone(SPEAKER_PIN, NOTE_G4);
  delay(150);
  tone(SPEAKER_PIN, NOTE_E5);
  delay(150);
  tone(SPEAKER_PIN, NOTE_C5);
  delay(150);
  tone(SPEAKER_PIN, NOTE_D5);
  delay(150);
  tone(SPEAKER_PIN, NOTE_G5);
  delay(150);
  noTone(SPEAKER_PIN);
}

void playDifficultyUpSound() {
  for (byte i = 0; i < 3; i++) {
    for (byte j = 0; j < 4; j++) {
      digitalWrite(ledPins[j], HIGH);
    }

    tone(SPEAKER_PIN, NOTE_C5 + (i * 100));
    delay(100);

    for (byte j = 0; j < 4; j++) {
      digitalWrite(ledPins[j], LOW);
    }

    noTone(SPEAKER_PIN);
    delay(100);
  }

  tone(SPEAKER_PIN, NOTE_C5);
  delay(100);
  tone(SPEAKER_PIN, NOTE_E5);
  delay(100);
  tone(SPEAKER_PIN, NOTE_G5);
  delay(100);
  tone(SPEAKER_PIN, NOTE_C5 + 300);
  delay(200);
  noTone(SPEAKER_PIN);
}

void loop() {
  gameSequence[gameIndex] = random(0, 4);
  gameIndex++;

  if (gameIndex >= MAX_GAME_LENGTH) {
    gameIndex = MAX_GAME_LENGTH - 1;
  }

  playSequence();

  if (!checkUserSequence()) {
    gameOver();
  }

  delay(300);

  if (gameIndex > 0) {
    playLevelUpSound();
    delay(300);

    if (gameIndex % 5 == 0) {
      difficulty++;

      if (difficulty > 3) {
        difficulty = 3;
      }

      Serial.print("Difficulty increased to: ");
      Serial.println(difficulty);
      playDifficultyUpSound();
      delay(300);
    }
  }
}

Reflection

One possible future use for this type of input/output system would be a reaction or memory-training game for students practicing focus and recall. To make the current build useful for that situation, I would need to make the enclosure more durable, improve the controls, and possibly add a display to show the player's score and level. The skill I would rely on most is debugging because getting the circuit to work required carefully checking connections, component placement, and code behavior.

Next step: I could further improve the game by adding a score system, more difficulty levels, or a way to save a player's high score.
