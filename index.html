My Project

Digital Output Extension

Project Goal

Making Arduino Play Music

I started with what I already knew about digital output from controlling an LED. Instead of only turning an LED on and off, I wanted my Arduino to produce sounds. I chose a piezo buzzer and a keypad so that the project could become more interactive.

What I Built On

In class, I learned how to use digital output to control an LED. I used that knowledge as the starting point for learning how Arduino can control a piezo buzzer.

New Components

The new components I used were a piezo buzzer and a keypad. The keypad allows the project to receive input, while the piezo buzzer creates the output.

Research

Learning how the components work

Piezo Buzzer

I researched how to connect a piezo buzzer to an Arduino. I learned that the tone() function can make the buzzer play different frequencies. Higher and lower frequencies create different musical notes.

My Sources

I used ChatGPT and Arduino as sources while researching how the piezo buzzer works and how it can be controlled with Arduino code.

Reflection

Looking beyond this project

How Could This Be Useful?

A project like this could be useful for someone who needs an interactive way to practice recognizing sounds, notes, or keypad inputs. For example, it could eventually become a small educational game that uses different sounds as feedback.


What Would Need to Change?

To make my current build useful in a real situation, I would need to make the circuit more durable and create a better enclosure for the components. I could also add a display or other feedback system to make it easier for someone to use.


The Skill I Would Rely On Most

The skill I would rely on most is debugging. As I continue developing the project, I would need to carefully check my wiring, code, and component behavior whenever something does not work as expected.
